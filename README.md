# Jason-wx.github.io

Jekyll site (GitHub Pages compatible), styled after nrehiew.github.io.

- New post: add `_posts/YYYY-MM-DD-slug.md` with front matter `layout: post`, `title`, `subtitle`.
- Math: MathJax, use `$$...$$` (inline and display). Sidebar TOC is generated from `##`/`###`/`####`.
- Local preview: `bundle install && bundle exec jekyll serve`
